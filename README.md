## Introduction

This repository contains my solutions to five algorithm problems completed as part of the HackerRank Algorithms & GitHub Coding Portfolio activity. The solutions are implemented in C with their time and space complexity analysis.

## Problems and Solutions

### 1. Mini-Max Sum

**Approach:**
- Calculate the total sum of all elements.
- Find the minimum and maximum values.
- Minimum sum = total sum - maximum value.
- Maximum sum = total sum - minimum value.

**Time Complexity:** O(N)  
**Auxiliary Space:** O(1)

---

### 2. Birthday Cake Candles

**Approach:**
- Find the maximum candle height.
- Count how many candles have that maximum height.

**Time Complexity:** O(N)  
**Auxiliary Space:** O(1)

---

### 3. Insertion Sort Part 1

**Approach:**
- Store the last element as the value to insert.
- Compare it with previous elements.
- Shift larger elements to the right.
- Insert the value into its correct position.

**Time Complexity:** O(N)  
**Auxiliary Space:** O(1)

---

### 4. Binary Search

**Approach:**
- Use two pointers: left and right.
- Find the middle element.
- If the middle element is the target, return its index.
- If the target is larger, search the right half.
- Otherwise, search the left half.

**Time Complexity:** O(log N)  
**Auxiliary Space:** O(1)

---

### 5. Mark and Toys

**Approach:**
- Sort the prices in ascending order.
- Start buying from the cheapest toy.
- Continue while the total cost does not exceed the budget.

**Time Complexity:** O(N log N)  
**Auxiliary Space:** O(1) auxiliary space apart from sorting implementation.
